⚡ DICAS DE PERFORMANCE
═════════════════════════════════════════════════════════════════════

Para arquivos grandes (>100MB):
   • Implementar cache com @st.cache_data
   • Filtrar dados por período
   • Usar subsample

Usar:
   @st.cache_data
   def load_sim_data(file_path):
       return pd.read_csv(file_path)
